# Deep-Learning-Assignments-2022 – Collection Guide

Four deep-learning assignments (2022 edition), each in its own folder with a detailed README and per-part instructions.

## Contents
- `Assignment 1/` – P1–P3 (vision, optimization); includes `README.md` for each part.
- `Assignment 2/` – P1–P3 (CNNs, regularization, sequence models); per-part READMEs.
- `Assignment 3/` – multi-part assignment with provided notebooks and READMEs.
- `Assignment 4/` – final multi-part assignment with prompts and starter code.

## How to work on an assignment
1) Enter the assignment folder (e.g., `Assignment 2`).  
2) Create/activate a fresh virtual environment.  
3) Install dependencies listed in that part's instructions (often within the part README).  
4) Run the notebook or script specified there.  
5) Save outputs/plots alongside the notebook; export to PDF if required.

## Notes
- Requirements differ across parts—install per part rather than globally.  
- Keep datasets outside git; follow download links provided inside each part README.  
- When adding new solutions, mirror the existing folder pattern and include a short README and `requirements.txt` for the new part.
