# Berkeley CS285 PyTorch Solutions – Guide

Unofficial PyTorch ports of Berkeley CS285 homeworks (hw1–hw5). Each homework folder contains its own README and `requirements.txt`.

## Contents
- `hw1` – intro RL + behavior cloning.  
- `hw2` – policy gradients.  
- `hw3` – model-based RL.  
- `hw4` – advanced topics (e.g., MBPO variants).  
- `hw5` – exploration and SAC extensions.

## How to run a homework
1) Enter the homework folder (e.g., `hw3`).  
2) Create/activate a fresh virtual environment.  
3) Install dependencies: `pip install -r requirements.txt`.  
4) Follow the local README for scripts/notebooks to execute (typically `python main.py` or Jupyter notebooks).  
5) Save outputs/plots locally; avoid committing large logs.

## Notes
- Some homeworks may need MuJoCo/Atari extras—install only when the local README requests them.  
- These are reference solutions; attempt your own implementation before consulting them if you are taking the course.
