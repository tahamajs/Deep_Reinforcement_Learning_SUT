# Deep-RL-Assignments – Collection Guide

Five reinforcement-learning assignments plus subparts, each with its own README and requirements.

## Contents
- `Assignment1/` – introductory RL; includes `requirements.txt` and README.  
- `Assignment2/` – VI/PI/DQN track (`hw2-VI-PI-DQN`) with subfolders `Q2-VI-PI`, `Q3-3-DQN`, each with their own README/requirements.  
- `Assignment3/` – continuation with notebooks and `requirements.txt`.  
- `Assignment4/` – advanced tasks; see README in the folder.  
- `Assignment5/` – capstone-style assignment with README.  
- `Assignment 6/` (if present) – ensure to read local instructions; some assets may be large.

## How to run
1) Navigate to the specific assignment folder.  
2) Create/activate a new virtual environment.  
3) Install that folder's `requirements.txt` (subparts may have their own files).  
4) Execute notebooks or scripts as directed by the local README.  
5) Keep generated data/plots inside the assignment folder; avoid committing large artifacts.

## Tips
- Subpart requirements (e.g., `hw2-VI-PI-DQN/Q2-VI-PI/requirements.txt`) can differ; install per subpart.  
- Atari/MuJoCo dependencies appear only in some tasks—install them only when needed.
