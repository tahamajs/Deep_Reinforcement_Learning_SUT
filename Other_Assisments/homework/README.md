# homework – Supplementary Homework Set

Supplementary homework collection (non-primary course). Subfolders `hw1`–`hw5` each contain prompts, code, and solutions; some `hw5` variants include original experiment/meta/SAC branches.

## How to run
1) Enter the desired `hwX/` folder.  
2) Create/activate a new virtual environment.  
3) Install its `requirements.txt` (or `requirements-modern.txt` / `requirements_colab.txt` if provided for Colab).  
4) Open the notebook or script indicated in that folder's README.  
5) Save outputs locally; export to PDF if requested.

## Folder hints
- `hw1` – intro tasks (classic control); modern/colab requirements available.  
- `hw2` – value-based methods.  
- `hw3` – policy gradients.  
- `hw4` – advanced topics.  
- `hw5` – multiple variants (`original_exp`, `original_meta`, `original_sac`) plus consolidated README.
