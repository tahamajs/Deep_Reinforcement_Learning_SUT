# homework_fall2022 – Course Homework Set (Fall 2022)

Homework folders `hw1`–`hw5` with their own READMEs and Colab-friendly requirements.

## How to run
1) Enter the chosen folder (e.g., `hw3`).  
2) Create/activate a fresh virtual environment (or use Colab).  
3) Install dependencies from `requirements.txt` or `requirements_colab.txt`.  
4) Open the notebook(s) referenced in that folder's README.  
5) Keep outputs (plots/checkpoints) within the folder; export to PDF when needed.

## Notes
- Colab-specific requirements are provided for quick cloud execution.  
- Follow the per-folder README for exact tasks and submission expectations.
