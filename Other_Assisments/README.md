# Other_Assisments/ – External & Supplementary Assignment Sets

This folder aggregates several independent assignment collections. Each subfolder carries its own README and requirements; use those for details.

## Collections
- **Deep-Learning-Assignments-2022/** – Four DL assignments (P1–P4) with separate `README` files for each part.
- **Deep-RL-Assignments/** – Five-assignment series plus supporting code (VI/PI/DQN, PPO, etc.).
- **Reinforcement-Learning-Assignments/** – Additional RL homework set with its own README.
- **Reinforcement_learning/** – Smaller standalone RL projects (bandits, PPO LunarLander, multi-agent DQN, etc.).
- **berkeley-deep-RL-pytorch-solutions/** – CS285 homework ports (hw1–hw5) in PyTorch.
- **deep-rl-class/** – Notebook units for a deep RL class, organized by unit.
- **homework/** and **homework_fall2022/** – Course-specific homework folders (multiple assignments each), many with Colab-friendly requirements files.

## How to use
1. Pick the collection relevant to your course or reference.
2. Read the subfolder README to understand scope and install instructions.
3. Create a fresh environment per collection (requirements differ across courses).

If you add new external materials, place them in a new subfolder with its own README and `requirements.txt`.
