# deep-rl-class – Notebook Units

Collection of unit-based notebooks for an external deep RL class. Units are organized by number (e.g., `unit1`, `unit2`, `unit4`, `unit6`), each with its own `requirements-unitX.txt`.

## How to use
1) Pick a unit folder (e.g., `notebooks/unit4`).  
2) Create/activate a virtual environment.  
3) Install the unit-specific requirements file (e.g., `pip install -r requirements-unit4.txt`).  
4) Launch Jupyter (`jupyter lab`) and open the notebook(s) in that unit.  
5) Keep outputs within the unit folder; avoid committing large artifacts.

## Notes
- Requirements vary by unit; do not mix installs across units.  
- Units are largely independent—start with lower numbers if you need foundational coverage.
