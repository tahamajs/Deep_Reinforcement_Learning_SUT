# HW1 – Introduction & Classic Control Warm-Up

## Contents
- `descriptions/HW1_Questions.pdf` – assignment prompt.
- `base_code/HW1_Notebook.ipynb` – starter notebook for students.
- `code/HW1_Notebook.ipynb` – working area with required TODOs; includes `requirements.txt` and a reference ZIP (`ppo_MountainCar.zip`).
- `answer/HW1_Notebook_Solution.ipynb` – filled solution notebook and template PDF; includes its own `requirements.txt`.

## Setup
1. Create a virtual environment (Python 3.8+).
2. Install dependencies:
   ```bash
   pip install -r code/requirements.txt
   ```
   Use `base_code/requirements.txt` or `answer/requirements.txt` if you prefer those environments.
3. Launch `jupyter lab` and open the notebook you intend to work on.

## Tips
- Run cells in order; keep a copy of your completed notebook separate from the solution file.
- The MountainCar PPO ZIP contains a reference model; use it for comparison only if allowed by your instructions.
- When submitting, export to PDF if requested in the prompt.
