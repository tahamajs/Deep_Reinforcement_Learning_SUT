# CA30 — Curriculum Assignment 30

## Overview

CA30 is a scaffold for research-style assignments. This README contains long-form guidance for mapping theory to implementation, designing experiments, and producing reproducible deliverables.

## Learning Goals

- Implement modular, testable code.
- Map math precisely to code with shape contracts.
- Produce reproducible experiments with saved artifacts.

## Files & Layout

- `src/`, `notebooks/`, `configs/`, `tests/`, `pictures/`.

Problem description

Choose a research question, derive the math, and design experiments to test the hypothesis.

Implementation notes

- Use dataclasses for configs and ensure deterministic seeding.
- Keep notebooks for execution; `src/` must be import-safe.

Experiments

- Baseline and variant runs, ablations, seed sweeps.
