\section{Introduction}
Machine learning research relies on reproducible, well-documented experiments. However, real-world datasets often introduce confounding factors that obscure the effects of algorithmic choices. Synthetic benchmarks, by contrast, offer a controlled setting to rigorously evaluate models and training procedures. In this work, we introduce a synthetic regression benchmark for CA26, focusing on the interplay between model capacity, loss function robustness, and noise. Our goal is to provide a template for transparent, replicable research, with all code, data, and results available for inspection.

\section{Related Work}
\label{sec:related}
Synthetic regression tasks have long been used to study bias-variance tradeoffs and robustness in machine learning. Early work by \citet{breiman1996bagging} used synthetic data to analyze ensemble methods. Robust regression has been explored using synthetic outlier injection \citep{huber1964robust, ghosh2017robust}. Modern benchmarks such as scikit-learn's toy datasets \citep{pedregosa2011scikit} and the UCI repository \citep{Dua:2019} provide real and synthetic regression tasks. Our work builds on these by emphasizing reproducibility, modularity, and extensibility, following best practices from \citet{paszke2019pytorch} and \citet{wolf2020transformers}.

\section{Background and Problem Formulation}
\label{sec:background}
Consider the regression problem: given $x \in [0,1]$, predict $y = f(x) + \varepsilon$, where $f(x)$ is a smooth function and $\varepsilon$ is noise. The choice of $f$, noise distribution, and model class determines the difficulty and nature of the task. We focus on $f(x) = \sin(2\pi x)$, a periodic, nonlinear function, and $\varepsilon \sim \mathcal{N}(0, \sigma^2)$, allowing controlled study of robustness.

Loss functions play a central role in regression. The mean squared error (MSE) is optimal for Gaussian noise but sensitive to outliers. The Huber loss interpolates between MSE and mean absolute error (MAE), providing robustness. Model capacity, determined by the number and size of hidden layers, affects bias and variance. Our benchmark enables systematic study of these factors.

\section{Dataset Construction}
\label{sec:dataset}
The dataset consists of $N$ samples $(x_i, y_i)$, with $x_i \sim \mathrm{Uniform}(0,1)$ and $y_i = \sin(2\pi x_i) + \varepsilon_i$, $\varepsilon_i \sim \mathcal{N}(0, \sigma^2)$. The generator is implemented in \texttt{src/data.py} as \texttt{SyntheticRegressionDataset}. Key parameters include sample size, noise standard deviation, and random seed. The dataset is split into training, validation, and test sets (70/15/15). No additional preprocessing is required, but normalization is supported.

\subsection{Properties and Challenges}
\begin{itemize}
  \item \textbf{Periodicity:} The target function is periodic, requiring non-linear modeling.
  \item \textbf{Noise:} Adjustable noise enables robustness studies.
  \item \textbf{No outliers by default:} Outliers can be simulated by increasing noise.
\end{itemize}

\section{Methodology}
\label{sec:methodology}
We use fully-connected multilayer perceptrons (MLPs) with configurable depth and width. The forward pass is:
\begin{align}
  h_0 &= x \\
  h_{k+1} &= \phi(W_k h_k + b_k) \quad \text{for } k = 0, \dots, L-1 \\
  \hat{y} &= W_L h_L + b_L
\end{align}
where $\phi$ is the activation function. Supported activations: ReLU, Tanh, Identity. Model capacity is controlled by hidden layer sizes. Implementation uses PyTorch's \texttt{nn.Sequential} for modularity.

\subsection{Loss Functions}
\label{sec:loss}
	extbf{Mean Squared Error (MSE):}
\begin{equation}
\mathcal{L}_{\mathrm{MSE}}(\hat{y}, y) = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2.
\end{equation}
MSE is optimal for Gaussian noise but sensitive to outliers.

	extbf{Huber Loss:}
\begin{equation}
H_\delta(r) = \begin{cases}
\frac{1}{2} r^2 & \text{if } |r| \leq \delta, \\
\delta(|r| - \frac{1}{2}\delta) & \text{otherwise}
\end{cases}
\end{equation}
where $r = y - \hat{y}$. Huber loss is robust to outliers and differentiable everywhere.

Both losses are implemented with shape checks. See Appendix~\ref{app:code}.

Evaluation metrics include MSE, MAE, RMSE, and $R^2$. Recommended figures: loss curves, prediction scatter plots, residual histograms, and aggregated results.

from __future__ import annotations
from typing import Iterator, Tuple
import numpy as np
import torch
from torch.utils.data import Dataset

class SyntheticRegressionDataset(Dataset):
    def __init__(self, n_samples: int = 1000, noise_std: float = 0.1, seed: int | None = None):
        self.n_samples = int(n_samples)
        self.noise_std = float(noise_std)
        rng = np.random.RandomState(seed)
        self.x = rng.rand(self.n_samples, 1).astype(np.float32)
        self.y = np.sin(2 * np.pi * self.x) + rng.randn(self.n_samples, 1).astype(np.float32) * self.noise_std

    def __len__(self) -> int:
        return self.n_samples

    def __getitem__(self, idx: int) -> Tuple[torch.Tensor, torch.Tensor]:
        x = torch.from_numpy(self.x[idx])
        y = torch.from_numpy(self.y[idx])
        return x, y
\end{lstlisting}

\subsection{Training Loop}
\begin{lstlisting}[caption=Complete training function]
def train_one_epoch(model, loader, optim, device):
    model.train()
    total_loss = 0.0
    n = 0
    for x, y in loader:
        x = x.to(device)
        y = y.to(device)
        pred = model(x)
        loss = mse_loss(pred, y)
        optim.zero_grad()
        loss.backward()
        optim.step()
        total_loss += float(loss.item()) * x.shape[0]
        n += x.shape[0]
    return total_loss / max(1, n)
\end{lstlisting}

We consider a scalar regression problem: given input $x\in[0,1]$, predict target
\begin{equation}
y = f(x) + \varepsilon, \qquad f(x) = \sin(2\pi x),\quad \varepsilon \sim \mathcal{N}(0,\sigma^2).
\end{equation}
This function is chosen because it is smooth, periodic, and challenging for low-capacity models to fit accurately without overfitting.

  \item \textbf{seed:} for reproducible draws using NumPy's random state.

\section{Model Family}
We use simple fully-connected multilayer perceptrons (MLPs). The architecture is parameterized by input dimension $d_{in}$, a hidden sizes tuple $H = [h_1, h_2, \dots, h_L]$, and an output dimension $d_{out}$.

\subsection{Mathematical Formulation}
The forward pass can be written recursively as:
\begin{align}
h_0 &= x \\
h_{k+1} &= \phi(W_k h_k + b_k) \quad \text{for } k = 0, \dots, L-1 \\
\hat{y} &= W_L h_L + b_L
\end{align}
where $\phi$ denotes the activation function, $W_k$ are weight matrices, and $b_k$ are bias vectors.

For our scalar regression task, $d_{in} = 1$, $d_{out} = 1$, and typical $H = [64, 64]$ gives a 2-hidden-layer MLP.

\subsection{Implementation Details}
The implemented network in \texttt{src/model.py} stacks linear layers with configurable activation functions. The code uses PyTorch's \texttt{nn.Sequential} for clean composition:
\begin{lstlisting}[caption=MLP implementation]
class MLP(nn.Module):
    def __init__(self, input_dim: int, hidden_dims: Iterable[int], output_dim: int, activation: str = "relu"):
        super().__init__()
        dims = [int(input_dim), *[int(h) for h in hidden_dims], int(output_dim)]
        layers = []
        for i in range(len(dims) - 1):
            layers.append(nn.Linear(dims[i], dims[i + 1]))
            if i < len(dims) - 2:
                layers.append(get_activation(activation))
        self.net = nn.Sequential(*layers)
\end{lstlisting}

\subsection{Activation Functions}
Supported activations include:
\begin{itemize}
  \item ReLU: $\phi(z) = \max(0, z)$
  \item Tanh: $\phi(z) = \tanh(z)$
  \item Identity: $\phi(z) = z$
\end{itemize}
ReLU is the default due to its simplicity and effectiveness in deep networks.

\subsection{Initialization and Practical Notes}
Default PyTorch initializers are used (Kaiming uniform for ReLU, Xavier for others). For reproducibility across different PyTorch versions or frameworks, explicit initialization can be added:
\begin{lstlisting}[caption=Example explicit initialization]
def init_weights(m):

        nn.init.xavier_uniform_(m.weight)
        nn.init.zeros_(m.bias)
model.apply(init_weights)
\end{lstlisting}

Model capacity is controlled by the number and size of hidden layers. For this task, 1-2 hidden layers with 16-128 units are sufficient.

\section{Loss Functions}
This project implements two losses, chosen to illustrate different robustness properties.

\subsection{Mean Squared Error (MSE)}
\begin{equation}
\mathcal{L}_{\mathrm{MSE}}(\hat{y}, y) = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2.
\end{equation}
MSE penalizes large errors quadratically, making it sensitive to outliers. It's the maximum likelihood estimator under Gaussian noise assumptions.

\subsection{Huber Loss (Smooth L1)}
The Huber loss combines quadratic and linear penalties:
\begin{equation}
H_\delta(r) = \begin{cases}
\frac{1}{2} r^2 & \text{if } |r| \leq \delta, \\
\delta(|r| - \frac{1}{2}\delta) & \text{otherwise,}
\end{cases}
\end{equation}
where $r = y - \hat{y}$. The parameter $\delta$ controls the transition point. For $\delta = 1$, it's approximately L1 for large errors and L2 for small errors.

\subsection{Implementation and Shape Checks}
Both losses include shape validation:
\begin{lstlisting}[caption=Loss implementations]
def mse_loss(pred: torch.Tensor, target: torch.Tensor) -> torch.Tensor:
    if pred.shape != target.shape:
        raise ValueError(f"Shape mismatch: {pred.shape} vs {target.shape}")
    return torch.mean((pred - target) ** 2)

def huber_loss(pred: torch.Tensor, target: torch.Tensor, delta: float = 1.0) -> torch.Tensor:
    diff = pred - target
    abs_diff = torch.abs(diff)
    quadratic = torch.minimum(abs_diff, torch.tensor(delta, device=abs_diff.device))
    linear = abs_diff - quadratic
    return torch.mean(0.5 * quadratic ** 2 + delta * linear)
\end{lstlisting}

\subsection{Robustness Comparison}
MSE is optimal for Gaussian noise but can be dominated by outliers. Huber loss provides robustness while maintaining differentiability. In experiments, we compare their performance across different noise levels.

def evaluate_model(model, test_loader, device):
    model.eval()
    preds, targets = [], []
    with torch.no_grad():
        for x, y in test_loader:
            x, y = x.to(device), y.to(device)
            pred = model(x)
            preds.append(pred.cpu())
            targets.append(y.cpu())
    preds = torch.cat(preds)
    targets = torch.cat(targets)
    mse = torch.mean((preds - targets) ** 2).item()
    mae = torch.mean(torch.abs(preds - targets)).item()
    return {"mse": mse, "mae": mae}
\end{lstlisting}

\section{Error Analysis and Discussion}
\subsection{Convergence Behavior}
MSE typically converges faster on clean data but can be unstable with outliers. Huber loss provides more stable optimization at the cost of slightly slower convergence.

\subsection{Bias-Variance Tradeoff}
Smaller models (e.g., MLP(16,)) show higher bias but lower variance. Larger models can overfit the noise, especially with low regularization.

\subsection{Loss Function Sensitivity}
Huber loss with small $\delta$ behaves like L1 loss, providing robustness but potentially slower convergence. Large $\delta$ approaches MSE behavior.

class SyntheticRegressionDataset(Dataset):

        self.n_samples = int(n_samples)

    def __getitem__(self, idx: int) -> Tuple[torch.Tensor, torch.Tensor]:

        y = torch.from_numpy(self.y[idx])
        return x, y

\subsection{Training Loop}
\begin{lstlisting}[caption=Complete training function]
def train_one_epoch(model, loader, optim, device):
    model.train()
    total_loss = 0.0
    n = 0
    for x, y in loader:
        x = x.to(device)
        y = y.to(device)
        pred = model(x)
        loss = mse_loss(pred, y)
        optim.zero_grad()
        loss.backward()
        optim.step()
        total_loss += float(loss.item()) * x.shape[0]
        n += x.shape[0]
    return total_loss / max(1, n)
\end{lstlisting}
