\begin{abstract}
We present SimGolf-Latent, an approach that integrates simulation-based global
search (SimGolf) with learned latent world models (DreamerV3's RSSM). When the
agent detects high decision importance (large TD-error or model uncertainty),
it resets imagination to stored latent checkpoints and performs global branching
search in latent space. Branch returns are penalized by model uncertainty and
aggregated to yield TD(\(\lambda\)) targets and policy updates. Our
implementation supports CEM branch proposals, uncertainty penalties, and
branch-to-real distillation. We provide algorithmic details, code, and an
experimental protocol for hard navigation tasks.
\end{abstract}

\section{Introduction}
Model-based reinforcement learning (RL) with learned latent world models has
demonstrated strong sample efficiency across many domains. However, long-horizon
planning under partial observability and sparse rewards remains challenging:
local greedy planning can miss viable long-range plans and backtracking behaviors.
SimGolf \cite{sim_golf} introduced simulation-based global search with episodic
resets to previously visited states; this work adapts SimGolf to operate entirely
in latent space using DreamerV3's RSSM, avoiding real-environment resets while
preserving the planner's exploratory power.

\section{Method}
\subsection{Latent dynamics and notation}
Let \(z_t\in\mathbb{R}^d\) denote the learned stochastic latent (RSSM). The
world model parameterized by \(\theta\) defines transitions \(p_\theta(z_{t+1}\mid z_t,a_t)\),
a decoder \(p_\theta(o_t\mid z_t)\), a reward head \(r_\theta(z_t)\), and (optionally)
reward uncertainty \(\sigma_{r,\theta}(z_t)\). The actor \(\pi_\phi(a\mid z)\)
and critic \(v_\psi(z)\) operate in latent space.

\subsection{Checkpoint buffer and trigger}
We maintain a checkpoint buffer \(C\) of latents \(z\) with metadata (TD-error,
entropy, step). A trigger function fires when a monitored metric exceeds
thresholds (TD-error, ensemble uncertainty, or entropy) and obeys a cooldown.
Implementation: `planner.CheckpointBuffer` and `planner.triggers.should_trigger`.

\subsection{Branch generation and scoring}
From a saved latent \(z_s\), we generate \(B\) branches of horizon \(H\).
Branches may be generated by (i) sampling actions from \(\pi_\phi\) or
(ii) CEM optimization over action sequences (see `planner.advanced`).
Let branch \(b\) produce predicted rewards \(r_{s,b,t}\) and discounts \(\gamma_{s,b,t}\).
If the model provides a reward uncertainty \(\sigma_{s,b,t}\), we form
an uncertainty-penalized reward \(r'_{s,b,t}=r_{s,b,t}-\kappa\sigma_{s,b,t}\)
with \(\kappa\ge0\).
We define the bootstrapped branch return
\begin{equation}
\hat R_b \;=\; \sum_{k=0}^{H-1}\Big(\prod_{j=0}^{k-1}\gamma_{s,b,j}\Big) r'_{s,b,k}
 \Big(\prod_{j=0}^{H-1}\gamma_{s,b,j}\Big) v_\psi(z_{s,b,H}).
\label{eq:branch-return}
\end{equation}
Branches are ranked by \(\hat R_b\). We either (A) update the policy using a
distribution over first actions of top-k branches, or (B) use the best branch's
first action to bias the next real action (with safety gates).

\subsection{Learning from imagined branches}
We treat branches as imagined trajectories and compute TD(\(\lambda\)) targets:
\begin{equation}
G_t = r_t + \gamma_t\big((1-\lambda)v_\psi(z_{t+1}) + \lambda G_{t+1}\big).
\label{eq:td-lambda}
\end{equation}
The critic minimizes \(L_{\rm critic}=\mathbb{E}\|v_\psi(z_t)-\mathrm{stopgrad}(G_t)\|^2\)
and the actor is updated with advantage-weighted policy gradient on imagined samples:
\[
L_\pi = -\mathbb{E}[\log\pi_\phi(a_t\mid z_t)\,\mathrm{stopgrad}(G_t-v_\psi(z_t))] - \eta\mathcal{H}(\pi_\phi).
\]
We implement TD(\(\lambda\)) aggregation in `DreamerAgent.update_actor_critic_from_branches`.

\subsection{CEM for branch proposal}
Optionally, CEM searches for high-return action sequences in latent space by
optimizing a population of action sequences using the world model; details in
`planner.advanced._run_cem`. CEM is warm-started with policy samples to improve efficiency.

\section{Implementation details}
We provide a production-ready scaffold:
\begin{itemize}
\item `planner/checkpoint_buffer.py` — storage and prioritized sampling.
\item `planner/simgolf_latent.py` — simple policy-sampled branching.
\item `planner/advanced.py` — CEM-based branch proposal and uncertainty handling.
\item `planner/distill.py` — branch-to-action distillation utilities.
\item `scripts/train_simgolf_dreamerv3.py` — training scaffold (stubs for RSSM/actor/value).
\item Integration with an existing Dreamer agent: `archive/.../dreamer_agent.py` (hooks for checkpointing, triggering and imagined updates).
\end{itemize}
All modules include type hints and small unit tests under `CA13/tests`.

\section{Related work}
DreamerV1--V3 (Hafner et al.) introduced latent RSSMs and imagination-based policy
learning. SimGolf introduced episodic resets with branching search. CEM-MPC is a
classical planner; our CEM runs in latent-space to produce candidate action
sequences. Prioritized replay and contrastive representation learning inform our
checkpoint scoring and buffer design.

\section{Discussion and limitations}
Planner efficacy depends on model quality; high \(\kappa\) reduces optimism but may over-penalize. CEM increases compute cost; use sparse triggering and cooldowns. Latent resets assume RSSM captures all necessary state — a known limitation when observations contain non-modeled hidden variables.

\section{Conclusion}
We proposed SimGolf-Latent, a practical method for integrating global branching
search with Dreamer-style latent imagination. We provide code, tests, and a
clear experimental recipe to evaluate on hard navigation tasks.

\appendix
\section{TD(\(\lambda\)) derivation and implementation notes}
Equation~\eqref{eq:td-lambda} is implemented as a backward recursion over each
imagined branch. In practice we compute per-branch targets and aggregate top-k
branches before updating the critic and actor (see `DreamerAgent.update_actor_critic_from_branches`).

\section{Uncertainty penalty rationale}
The penalty \(r' = r - \kappa\sigma_r\) is a simple pessimism heuristic: if
predicted reward variance \(\sigma_r\) is high, the branch return is reduced to
avoid over-optimistic selection. Formal bounds require assumptions on model bias
and are left for future work.
