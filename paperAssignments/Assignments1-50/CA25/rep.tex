\section{Methods}
\subsection{Model}
We use a fully connected multilayer perceptron (MLP) with ReLU activations. For an input $x\in\mathbb{R}^{D}$, layer computations are:
\begin{align}
    h^{(0)} &= x, \\
    z^{(l)} &= W^{(l)} h^{(l-1)} + b^{(l)}, \\
    h^{(l)} &= \phi(z^{(l)}) \quad (\phi=\mathrm{ReLU})
\end{align}
The final output is linear $y = W^{(L)} h^{(L-1)} + b^{(L)}$. For classification we interpret $y$ as logits and apply softmax.

\subsection{Loss Functions}
Mean squared error (MSE) for regression:
\begin{equation}
    \mathcal{L}_{\mathrm{MSE}} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2
\end{equation}
Cross-entropy for classification (logits $z$):
\begin{equation}
    \mathcal{L}_{\mathrm{CE}} = -\frac{1}{N} \sum_{i=1}^N \log \frac{e^{z_{i,c_i}}}{\sum_{c} e^{z_{i,c}}}
\end{equation}
