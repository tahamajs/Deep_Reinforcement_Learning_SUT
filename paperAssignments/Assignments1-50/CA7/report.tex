\begin{abstract}
We propose GET-ROPR, a practical method to incorporate backward-view TD($\lambda$)
eligibility traces into recurrent off-policy reinforcement learning. This report
summarizes the algorithm, theoretical motivation, and experimental plan.
\end{abstract}

\section{Introduction}
Partial observability requires memory. Recurrent critics trained off-policy suffer
from stale hidden states and truncated BPTT. GET-ROPR reintroduces long-horizon
credit assignment via eligibility traces adapted to recurrent architectures.

\section{Method}
\subsection{Notation}
Observations \(o_t\), actions \(a_t\), rewards \(r_t\), done \(d_t\). Critic \(Q_\phi(o_t,h_t,a_t)\).
\subsection{Backward-View Traces}
We define
\[
e_t = \bar{\rho}_t (\lambda \gamma e_{t-1} + \nabla_\phi Q_\phi(o_t,h_t,a_t)),
\qquad
\delta_t = r_t + \gamma (1-d_t) Q_{\bar\phi}(o_{t+1},h_{t+1},a_{t+1}) - Q_\phi(o_t,h_t,a_t).
\]
The gradient estimate is \(g=\sum_t \delta_t e_t\).

\subsection{Lambda-Returns (Forward View)}
An equivalent forward-view loss is
\[
\mathcal{L}=\frac{1}{2}\sum_t (G_t^\lambda - Q_t)^2,\quad
G_t^\lambda = Q_t + \sum_{n=1}^{L-t} (\gamma\lambda)^{n-1}\Big(\prod_{i=1}^{n-1}\bar{\rho}_{t+i}\Big)\delta_{t+n-1}.
\]
