# archive/No Answer – Practice-Only Notebooks

Question-only notebooks for CA01–CA19. File names follow `CAxx.ipynb` and mirror the solved versions in `archive/Solutions/`.

Workflow:
1. Open the desired `CAxx.ipynb` in Jupyter.
2. Work through the prompts and TODOs without consulting solutions.
3. When finished, compare with the corresponding folder in `archive/Solutions/`.

Install requirements from the matching solution folder if a `requirements.txt` is absent here.
