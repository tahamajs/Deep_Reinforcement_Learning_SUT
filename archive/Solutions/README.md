# archive/Solutions – Answer Keys for CAs

Contains fully solved versions of Computer Assignments CA01–CA19. Folder names follow `CAxx_<topic>` and typically include:
- Solved notebooks (`.ipynb`)
- Python helpers/modules
- Figures or logs produced by the solution
- A local README with run instructions and dependencies

Use these after attempting the matching prompt in `archive/No Answer/`. Install the per-CA `requirements.txt` before executing notebooks.
