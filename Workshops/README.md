# Workshops/ – Hands-On Sessions

Six workshop folders with runnable notebooks focused on practice.

## Sessions
- **Workshop-1-Material** – Intro notebooks (general RL warm-up, PyGame demo).
- **Workshop-2-Material** – DP, MC, TD, and DQN on LunarLander (4 notebooks).
- **Workshop-3-Material** – Intermediate practice set.
- **Workshop-4-Material** – Additional applied exercises.
- **Workshop-5-Material** – Model-based planning drills: CEM, DynaQ, MCTS (+ assets).
- **Workshop-6-Material** – Capstone workshop notebook.

## How to run
1. Create a fresh Python environment with PyTorch, Gymnasium, and Jupyter.
2. If a workshop has extra assets (e.g., Workshop 5), keep paths relative to the folder.
3. Launch `jupyter lab` inside the workshop directory and execute notebooks top-to-bottom.
