# Course Notes Index

This collection summarizes core themes in deep reinforcement learning. Use the links below to navigate topic-specific notes.

## Table of Contents
- [Introduction to RL](./intro-to-rl.md) — fundamentals, MDPs, POMDPs, policies, Bellman equations.
- [Value-Based Methods](./value-based.md) and [Value-Based II](./value-based2.md) — tabular to deep Q-learning, distributional RL, dueling/double DQN.
- [Policy-Based Methods](./policy-based.md) and [Policy-Based II](./policy-based2.md) — REINFORCE, actor-critic, PPO/A2C/A3C, entropy regularization.
- [Advanced Actor–Critic](./advanced.md) — PPO, DDPG, SAC, GAE.
- [Model-Based RL](./model-based.md) — dynamics learning, MPC, MBPO, Dreamer, MuZero.
- [Exploration](./exploration.md) — UCB, Thompson sampling, curiosity, RND, information gain.
- [Bandits](./bandits.md) — exploration–exploitation fundamentals and regret analysis.
- [Hierarchical RL](./hierarchical.md) — options, subgoal discovery, HIRO/HAC.
- [Imitation Learning](./imitation.md) — BC, DAgger, GAIL/AIRL, hybrid offline IL.
- [Inverse RL](./inverse.md) — reward recovery via max-margin, MaxEnt, AIRL.
- [Offline RL](./offline.md) — conservative/value-regularized algorithms (BCQ, CQL, IQL).
- [Meta-RL](./meta.md) — RL\(^2\), MAML, latent context methods (PEARL).
- [Multi-Agent RL](./multi-agent.md) — CTDE (MADDPG/MAPPO), value decomposition (VDN/QMIX), coordination.
- [Phase 2 Primer](./intro-to-phase2.md) — math foundations for policy optimization and concentration bounds.

## How to Use These Notes
- Each page is self-contained and can be read in any order; start with **Introduction to RL** if you need a refresher.
- Algorithm-heavy pages include intuition, key equations, and practical tips; follow references for deeper dives.
- For hands-on work, pair these notes with notebooks and code in the repository that implement the described methods.
