# CA_extra/ – Supplemental Notebooks (s20–s28)

Additional exploratory or make-up notebooks numbered s20–s28. Each `.ipynb` is self-contained and can be opened directly in Jupyter.

## Usage
- Activate a Python 3.8+ environment with common DRL stacks (PyTorch, Gymnasium). If a notebook lists its own requirements, install them first.
- Open the notebook in `jupyter lab` and run top to bottom. Cells are ordered as mini-labs; many are safe to run on CPU.

## File list
- `s20.ipynb` – intro refresh
- `s21.ipynb` – exploration add-on
- `s22.ipynb` – policy gradient add-on
- `s23.ipynb` – value-based extensions
- `s24.ipynb` – model-based drill
- `s25.ipynb` – multi-agent add-on
- `s26.ipynb` – offline/safe RL add-on
- `s27.ipynb` – robustness/analysis
- `s28.ipynb` – open-topic sandbox

Use these as optional enrichment; they do not replace the main CA track in `archive/`.
