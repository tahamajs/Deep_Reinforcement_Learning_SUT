\begin{abstract}
این گزارش نسخه‌ی AMASA-Complex v2 را ارائه می‌کند که نسبت به نسخه‌ی اولیه، پروژه را به یک چارچوب در مقیاس درس پیشرفته تبدیل می‌کند. ارتقاهای اصلی شامل چهار الگوریتم (CQL، IQL، SAC-Lagrangian، PPO-Lagrangian)، پشته‌ی ایمنی ترکیبی (کنترل‌گر PID، سپر تصمیم‌درختی، منتقد ریسک مسیر)، سه خانواده سناریوی محیطی (عادی، اغتشاش‌یافته، خصمانه)، سامانه‌ی پیکربندی YAML با سازگاری عقب‌رو CLI، و خط لوله‌ی بنچمارک/جاروب PID است. نتایج نهایی شامل منحنی‌های پارتو، تحلیل ایمنی زمانی، و ارزیابی آستانه‌های چندسطحی است.
\end{abstract}

\section{مقدمه}
در کاربردهای ایمنی‌حساس، کیفیت یک عامل RL فقط با پاداش اندازه‌گیری نمی‌شود، بلکه باید همزمان سه پرسش پاسخ داده شود:
\begin{enumerate}
  \item آیا با داده‌ی آفلاین می‌توان شروع پایدار داشت؟
  \item آیا گذار آفلاین به آنلاین بدون واگرایی ایمنی انجام می‌شود؟
  \item آیا رفتار عامل در سناریوهای مخدوش قابل‌اعتماد باقی می‌ماند؟
\end{enumerate}

نسخه‌ی v2 برای پاسخ عملی به این سه محور طراحی شده است.

\section{دامنه‌ی پیاده‌سازی}
در مسیر \texttt{projects/amasa\_clean} موارد زیر پیاده‌سازی شده‌اند:
\begin{itemize}
  \item ماژول‌های جدید: \texttt{amasa/core, envs, offline, online, safety, bench}
  \item درخت تنظیمات: \texttt{configs/base}, \texttt{algorithms}, \texttt{scenarios}, \texttt{presets}, \texttt{sweep}, \texttt{thresholds}
  \item حفظ اسکریپت‌های قبلی با فلگ‌های جدید \texttt{--config --preset --scenario --algo}
  \item رانر یکپارچه \texttt{run\_experiment.py}
  \item تست واحد و اسموک
  \item گزارش انگلیسی و فارسی در قالب IEEE
\end{itemize}

\section{معماری}
\subsection{لایه‌های اصلی}
\begin{itemize}
  \item \textbf{لایه تنظیمات}: بارگذاری، ادغام و اعتبارسنجی YAML
  \item \textbf{لایه محیط}: دینامیک پایه + سناریوهای تنش
  \item \textbf{لایه یادگیری}: الگوریتم‌های آفلاین و آنلاین
  \item \textbf{لایه ایمنی}: تجمیع منتقد ریسک + سپر + PID
  \item \textbf{لایه ارزیابی}: اجرای ماتریس، تجمیع، نمودار و بررسی آستانه
\end{itemize}

\subsection{ترتیب ادغام پیکربندی}
ترتیب ادغام برای جلوگیری از ناسازگاری زمان اجرا:
\[
\text{base} \rightarrow \text{scenario} \rightarrow \text{algo} \rightarrow \text{preset}
\]
با این ترتیب، پریست \lr{smoke/full} در پایان اعمال می‌شود و بودجه‌ی اجرا حفظ می‌گردد.

\section{مدل محیط و سناریوها}
رابط مسئله ثابت مانده است:
\begin{itemize}
  \item حالت ۲۳ بعدی
  \item کنش ۷ بعدی گشتاور
  \item پاداش ترکیبی (شکل‌دهی + تکمیل)
  \item هزینه برای نقض محدودیت نیرو/کریدور
\end{itemize}

سناریوها:
\begin{itemize}
  \item \textbf{Nominal}: نویز ملایم
  \item \textbf{Perturbed}: نویز و شیفت دینامیکی قوی‌تر
  \item \textbf{Adversarial}: خرابی مشاهده و تاخیر شدیدتر
\end{itemize}

\section{مجموعه الگوریتم‌ها}
\subsection{آفلاین}
\subsubsection{CQL}
کاهش بیش‌برآورد روی کنش‌های خارج از توزیع با جمله محافظه‌کارانه:
\[
\mathcal{L}_{\text{critic}} = \mathcal{L}_{\text{TD}} + \alpha_{\text{CQL}}\mathcal{L}_{\text{cons}}
\]

\subsubsection{IQL}
ترکیب \lr{expectile value fitting} و \lr{advantage-weighted policy update} برای استخراج سیاست آفلاین پایدار.

\subsection{آنلاین امن}
\subsubsection{SAC-Lagrangian}
تابع هدف سیاست:
\[
\mathcal{L}_{\pi} = \mathbb{E}[\alpha \log\pi(a|s) - Q_r(s,a) + \lambda Q_c(s,a)]
\]

\subsubsection{PPO-Lagrangian}
مزیت ترکیبی:
\[
\hat{A}_{\lambda} = \hat{A}_r - \lambda \hat{A}_c
\]
با \lr{clipping} و برآورد جداگانه‌ی مزیت پاداش/هزینه.

\section{پشته ایمنی ترکیبی}
ترتیب اجرای نگهبان ایمنی:
\begin{enumerate}
  \item پیشنهاد کنش توسط سیاست
  \item امتیاز ریسک توسط منتقد ریسک
  \item تبدیل محافظه‌کارانه در ریسک بالا
  \item عبور از سپر تصمیم‌درختی
  \item اجرای کنش نهایی در محیط
  \item به‌روزرسانی \(\lambda\) با کنترل‌گر PID
\end{enumerate}

ثبت ایمنی در هر گام:
\texttt{lambda}, \texttt{risk\_score}, \texttt{shield\_blocked},
\texttt{cost}, \texttt{force}, \texttt{corridor\_violation}.

\section{جمع‌بندی}
AMASA-Complex v2 با حفظ سازگاری CLI قبلی، پروژه را به یک چارچوب واقعی‌تر برای تمرین \lr{offline-to-online safe RL} تبدیل کرده است. مسیر کدنویسی، تست، ارزیابی و گزارش‌دهی یکپارچه شده و تحلیل‌های پارتو و PID نشان می‌دهد که کیفیت سیاست به‌شدت به تنظیم کنترل‌گر ایمنی و سناریوی محیط وابسته است. این دقیقا همان نقطه‌ی آموزشی مورد نیاز برای پروژه‌های ایمنی‌حساس است.
