# QuestionsAndNotes/ – Session Q&A Packets

Pairs of PDFs for each session: a slide-aligned handout (`DRL_SXX.pdf`) and a question set (`DRL_SXX_Q.pdf`).

## How to use
1. Read `DRL_SXX_Q.pdf` to quiz yourself on the session material.
2. Consult `DRL_SXX.pdf` for detailed explanations and worked answers.
3. Match `XX` with lecture number to align with slides and homework.
